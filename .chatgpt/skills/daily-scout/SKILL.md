# Daily Scout

Use this skill for Morning AI Scout’s daily research and video planning run.

## Step-by-step morning run

1. **Read memory first.** Open `memory.md` before researching. Follow every rule in it. If it does not exist, create it with a `# Memory` heading.
2. **Set the time window.** Use the current date and time in India time (Asia/Kolkata). Research only items first published, announced, or launched during the previous 24 hours. State the exact window and time zone in the report. Label older items as background and do not count them as new.
3. **Find AI tools and news.** Search Product Hunt, Hacker News, Reddit, X, and official AI company blogs. Check primary announcements or product pages for details. Keep the source link and publication time for each candidate.
4. **Shortlist AI tools and news.** Follow `memory.md`: prioritize mostly free AI tools Dhanaraj can try today, and skip funding news. Remove duplicates, stale items, and unsupported claims. Rank the five most interesting distinct qualifying items. For each, give its name or headline, source link, publication time when available, and one concise line explaining why it matters. If fewer than five credible items qualify, say so rather than padding the list.
5. **Find AI research papers.** Search leading primary research sources: arXiv (including relevant AI, machine learning, language, vision, and robotics categories), OpenReview, ACL Anthology, CVF Open Access, PMLR, and official AI lab research pages. Discovery sources such as Hugging Face Daily Papers or Papers with Code may surface candidates, but verify every paper on its primary publisher or author page. Include only papers first posted or formally published in the previous 24 hours; an older paper with a new version is not new. Rank by relevance to Dhanaraj’s Gen AI studies, novelty, evidence, reproducibility, and practical learning value. Prefer papers with free full text and usable code or data. List up to five; if fewer qualify, say so. For each paper include its title, authors, first-post/publication time, primary link, whether it is a preprint or peer-reviewed publication, a plain-English summary of its contribution, why it matters, and a key caveat. Never describe a preprint as peer reviewed.
6. **Choose one video idea.** Choose the single strongest timely idea from both shortlists for Dhanaraj Esuru, an MCA student pursuing Gen AI. Explain why it fits his education and audience, what viewers can learn, and whether the main evidence is a paper, a tool, or news.
7. **Write hooks in three languages.** Provide three hook options, each written in Telugu, Hindi, and English. Keep each version natural, engaging, and faithful to the same idea. Do not translate technical claims in a way that changes their meaning.
8. **Give five major points in three languages.** Write exactly five concise outline points based on the selected story and video idea. Order them from context and what happened through evidence, implications, and a practical takeaway. For every point provide Telugu, Hindi, and English versions with the same facts and meaning. Include a source link for each point. Use different reliable source platforms across the points when available, and make clear which source supports each point. Do not invent details.
9. **Save the report.** Create `outputs/` if it does not exist. Save the finished report as `outputs/YYYY-MM-DD.md`, using today’s date in India time. Include both shortlists and use these headings:
   - `# Morning AI Scout — YYYY-MM-DD`
   - Research window with start and end time (Asia/Kolkata)
   - `## Top 5 AI tools and news`
   - `## Top 5 AI research papers`
   - `## Best video idea` with why it fits and evidence type
   - `## Hook options` with three options in Telugu, Hindi, and English
   - `## Five major points` with exactly five points in Telugu, Hindi, and English, each with a source link

   For each paper, include the title, authors, preprint or peer-reviewed status, a plain-English contribution summary, why it matters, a caveat, the primary source link, and first-post/publication time.
10. **Create the Google Doc.** After saving the report, use the connected Google Drive integration to find or create a folder named `AI Scout`. If that integration is unavailable, use an already-signed-in Google Drive browser session if available; do not automate sign-in. Create a Google Doc inside the folder titled `AI Scout – YYYY-MM-DD`, with the same date as the report and the full report content and source links. If a Doc with that exact title already exists in the folder, update it instead of making a duplicate. Verify the Doc is in the folder and matches the local report before claiming success. If neither Drive access path is available, or sign-in is required, keep the local report and state that the Doc was not created.
11. **Email the full report.** Use the connected Gmail integration to send the complete report, including both the AI tools/news shortlist and research-paper shortlist, plus the Google Doc link, to the authenticated Gmail account. Use subject `Morning AI Scout — YYYY-MM-DD`. Search Sent first and do not send a duplicate for a date already delivered. If the Doc could not be created, include the full report content and local file path and state that the Doc is unavailable. If Gmail is unavailable or no authenticated recipient can be resolved, do not guess an address; report that email delivery did not happen.
12. **Apply feedback next time.** When Dhanaraj gives feedback on a report, add a short rule dated with the feedback date to `memory.md`. Keep existing rules and follow all rules on future runs.
